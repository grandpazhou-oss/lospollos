# Smart Transportation Control Tower

Static demo build for route visualization, dispatch analysis, ESG heatmap, multi-language UI, and data upload templates.

## Local Preview

```bash
python3 -m http.server 8765
```

Open:

```text
http://127.0.0.1:8765/index.html
```

## Deploy

This folder is static and can be deployed to Netlify, GitHub Pages, or any static hosting service.

## Contents

- `index.html` - application page
- `data/routes-data.js` - route data
- `assets/` - image assets
- `templates/` - Excel templates and demo data
