# STCT v1.7 Color Role Ledger

| Role | Color | Non-color duplicate |
|---|---|---|
| Primary text / command | `#003b79` | label and button hierarchy |
| Informational track | `#1769aa` | solid, dashed, or dotted line pattern |
| Critical / selected | `#ed1b2f` | exclamation icon, status text, thicker stroke |
| Verified / resolved | `#0b6a38` | check icon and status text |
| Neutral boundary | `#c4d0dc` | border and spatial grouping |
| Focus | `#ffbf47` | 3px visible outline |
| Background | `#f4f7fa` / `#ffffff` | layout separation |

Color never carries route state, confidence, conflict, or verification alone.
