## 启动与停止

要求现有 Python 和已验证的 OR-Tools 环境。不自动安装依赖。Windows 可以设置 `STCT_PYTHON` 指向已安装 OR-Tools 的 Python。

Windows：在本目录双击 `start_windows.cmd`；停止使用 `stop_windows.cmd`。默认地址：

`http://127.0.0.1:8865/index.html?optPort=8887#/`

macOS / Linux（用已有运行环境，端口空闲才会启动）：

```sh
python3 scripts/local_trial.py start --web-port 8865 --opt-port 8887 --open
python3 scripts/local_trial.py stop
```

不通过 `file://` 连接求解服务：浏览器对此会发送不可识别来源的 `Origin: null`。请使用启动器提供的 HTTP 入口。

启动器只绑定 127.0.0.1，拒绝 8787、8877、8791；端口被占用会退出，不杀占用进程。停止时核对项目路径、PID 和创建时间，只关闭该启动器创建的进程。静态服务使用 Python 标准库 HTTP/1.1 和显式 JS/CSS 类型，Mac 与 Windows 共用代码。
