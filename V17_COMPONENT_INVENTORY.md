|---|---|---|---|

| Shared Fleet Timeline | Fleet Replay | select vehicle | buttons and keyboard focus |
| Offline Driver Steps | Local Projection selection | previous, next, reconnect | ordered step list |
| Telemetry Inspector | Telemetry Observation / Derived Telemetry | inspect | reported/derived table |
| Conflict Center | reconciliation conflicts | keep, retry, discard | dependency text and buttons |
| Recovery Workspace | Rolling Recovery Session | preview, apply, undo | plan revision handover details |
| Shift Review | ShiftReview recompute | export | long description and route table |
| Flight Recorder | domain events | select event | listbox keyboard model |
| Capsule Export | Operational Capsule | export JSON | downloaded file and hash audit |

No primary component is backed by static business facts alone.
