# STCT v1.8 Motion Meaning Ledger

| Motion | Meaning | Reduced Motion Alternative |
|---|---|---|
| Network flow morph | Planned route to current execution state | Static directional arrows and state labels |
| Depot pulse | Capacity stress | Numeric stress label and severity word |
| Trip handover | Execution state transition | State marker and trip timeline row |
| Dock queue propagation | Measured queue wait | Queue-minutes table |
| Cross-dock handoff | Custody transition | Handoff sequence table |

Motion never authorizes or auto-applies a planning or recovery decision.
